# Data manifest

Input files required to reproduce the manuscript analyses.

---

## Files

### 1. `Takacs_et_al_Supplementary_File_1_2026_07_06.xlsx`

Primary source workbook. Drug-response analyses use sheet `PCT_DRUG_RESPONSE`.
Variant-count and flowchart analyses also use sheet `VARIANTS`.

| Column | Type | Description |
|--------|------|-------------|
| `Model` / `PCT_ID` | string | Patient-derived xenograft (PDX) model identifier |
| `COMPOUND` / `Treatment` | string | Treatment compound name |
| `LEVEL` / `DDA score` | numeric | DDA (Digital Drug Assignment) score |
| `TimeToDouble` | numeric | Tumour doubling time (days); primary survival endpoint |
| `Day_Last` | numeric | Last observation day |
| `APPROVED` / `Approved` | string | Regulatory approval status |
| `On_label` | string | On-label use for this indication (`chemo` marks standard-of-care rows) |
| `TARGET` / `Treatment target` | string | Molecular target class of the compound |
| `BestResponse` | numeric | Best percentage change from baseline in tumour volume |
| `BestAvgResponse` | numeric | Average percentage change from baseline across measurement time points |
| `ResponseCategory` | string | Clinical response category |

**Used by:** all scripts in `src/`

---

### 2. `chemo_data_2024_12_06.csv`

Standard-of-care chemotherapy reference cohort used by the data-processing
flowchart.

| Column | Type | Description |
|--------|------|-------------|
| `Model` | string | PDX model identifier |
| `COMPOUND` | string | Chemotherapy agent name |
| `Treatment target` | string | `chemotherapy` or `Tubulin` |
| `TimeToDouble` | numeric | Tumour doubling time (days) |

**Used by:** `flowchart_final.py`

---

### 3. `non_assigned_merged.xlsx`

PDX records without molecular-profiling assignment (Non_assigned group).

| Column | Type | Description |
|--------|------|-------------|
| `Model` | string | PDX model identifier |
| `COMPOUND` | string | Treatment compound name |
| `TimeToDouble` | numeric | Tumour doubling time (days) |

**Used by:** `KM_PDX.py`

---

### 4. `Fig1a_PDX_Graphical_abstract.jpg`

Manuscript Fig. 1a source artwork (graphical abstract). This panel is not generated by the analysis scripts. `build_figure_panel_pack.py` copies it into the assembled Fig. 1 composite after the other scripts have been run.

---

### 5. Source-data builders (optional)

| File | Description |
|------|-------------|
| `build_source_data.py` | Builds Nature-style `Source_Data_*.xlsx` workbooks in this folder after the analysis scripts have been run. Generated workbooks are not committed. |
| `build_negative_scores_supplementary_table.py` | Builds the negative-DDA-score supplementary table. Requires an external compound–profile matrix that is not redistributed. |
| `INVENTORY.md` | Commands for the two builders above. |

**Used by:** reviewers who need the journal source-data Excel files; not required to regenerate figures.

---

## Notes

PDX models are identified by alphanumeric codes only; no personally identifiable
information is included.
